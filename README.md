# Lumolo — public catalog

This repository holds only what the **Lumolo** iOS app reads publicly:

- `v1/` — the video list: `manifest.json`, `blocked.json` and `catalog/{language}[-{COUNTRY}].{hash}.json`
  (channels reviewed by people; YouTube data refreshed at least every 25 days).
- `legal/` — [Privacy Policy](legal/PRIVACY_POLICY.md), [Terms of Use](legal/TERMS.md),
  [Help & support](legal/SUPPORT.md).

Everything here is generated and published automatically from the private project repository.
Do not edit it by hand — changes are overwritten on the next publish.

Videos are provided by YouTube and played with YouTube's embedded player
([YouTube Terms of Service](https://www.youtube.com/t/terms),
[Google Privacy Policy](https://policies.google.com/privacy)).
